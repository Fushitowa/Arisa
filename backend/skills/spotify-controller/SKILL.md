# Spotify Controller

Use the existing registered Spotify application. Inspect its visible window before acting. Search and select a song, artist, album, or playlist only when the user identifies it sufficiently; ask if “my favorite playlist” cannot be resolved from visible Spotify state. Use visible controls and verify the resulting playback state from the interface. Do not claim music is playing based only on a click. Do not purchase, send, or change account/security information. Spotify Web API integration is not configured in this project, so rely only on the actual desktop UI and explain any interface access limitation.
