# Text Editor

Use the existing registered Notepad application. Inspect the active window before writing, focus the editor, type only the content requested, then inspect again to verify. Save only when asked, using the normal Save dialog and a user-directed filename/location. Do not replace existing content, bulk-select/delete, or overwrite an existing file automatically. If content is already present and the request implies replacement, ask first. Never claim a file was saved unless the application confirms it.
